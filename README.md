# Kesia Silva — Portfólio

Site de portfólio da designer gráfica **Kesia Silva** (Florianópolis, SC).

Página única e estática (HTML + CSS + JS puro), sem etapa de build.

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
python3 -m http.server 8000
# depois acesse http://localhost:8000
```

## Estrutura

- `index.html` — conteúdo e estrutura das seções
- `styles.css` — sistema de design (cores, tipografia, layout)
- `main.js` — revelação no scroll e ano do rodapé

## Personalizar

- **Portfólio real:** a seção *Linguagem* (`#trabalho`) usa peças abstratas como
  placeholder. Troque os `figure.tile` por imagens reais dos projetos.
- **Contato:** ajuste o e-mail em `mailto:contato@kesiasilva.design` e o link do
  LinkedIn no `index.html`.
